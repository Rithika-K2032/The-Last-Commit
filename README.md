# The Last Commit

A futuristic hackathon registration platform built for Cherry Network.

## Features

- Futuristic hackathon landing page
- Live countdown
- Participant registration
- SQLite database
- Node.js + TypeScript backend
- Admin dashboard
- Registration analytics
- Track-wise statistics

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- TypeScript
- Express
- SQLite
